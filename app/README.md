# app/

Resolvr web application for app.resolvrapp.com: Laravel 12 (PHP 8.3+, MySQL) with Inertia.js v2 + React + TypeScript, installable as a PWA. Evidence is encrypted on the device (IndexedDB + Web Crypto); the server handles accounts, encrypted backups, AI drafting and the waitlist API.

Commands are in the [root README](../README.md#app). Build prompts: Phase 2 in [`../docs/PROMPTS.md`](../docs/PROMPTS.md).
