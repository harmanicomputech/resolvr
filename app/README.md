# app/

Resolvr web application for app.resolvrapp.com — Laravel 12 (PHP 8.3+, MySQL) with Inertia.js + React + TypeScript, installable as a PWA. Evidence is encrypted on the device (IndexedDB + Web Crypto); the server handles accounts, encrypted backups, AI drafting and the waitlist API.

Not scaffolded yet. Run prompt **P0.1** from [`../docs/PROMPTS.md`](../docs/PROMPTS.md) (it creates the Laravel project in this folder; `composer create-project` needs an empty folder, so it replaces this README), then Phase 2 (P2.0–P2.13).
